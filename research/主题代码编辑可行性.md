# Shoplazza 主题代码编辑能力与套餐边界 · 可行性结论 · ShotStart

> 用途：判定在当前 Shoplazza 试用 / AI 建站条件下，能在多大程度上改主题代码（在线编辑器、源码下载上传、Liquid 模板、自定义 CSS/JS/字体、静态 HTML 页），哪些页面为平台托管不可定制，以及明日现场 2 小时窗口内的复现风险。
> 调研时间：2026-11-20；调研范围：官方开发者文档、帮助中心、定价页公开信息。
> 约束：本结论不改后台、不改 `shotstart-copy\pages\` 任何 txt；所有 [待核实] 项未在实机验证前不上前台。

## 0. 结论先行

1. **代码编辑器原生存在**：后台 Online Store > Themes > 目标主题 `...` > **Edit code**；左侧目录树含 `layout / templates / sections / snippets / assets / config / locales`，可在各目录 Add new file，文件支持 copy / rename / delete；Save 后按文件版本回滚（Current 下拉按保存时间列版本）；liquid / json / js / css 支持按需格式化，格式化对所有上传主题（后台或 CLI 上传）可用。
2. **源码可下载与再上传**：主题 Actions 菜单含 Download theme file；主题列表右上有 Upload theme 入口；本地可用 Shoplazza CLI + VS Code 开发后再上传。
3. **模板语言为 Shoplazza Liquid**（Liquid + HTML/CSS/JS/JSON）：`sections/*.liquid` 内 schema 定义 settings / blocks / presets；section 可带专属 CSS/JS 资源（Section assets）；snippet 用 `{% render %}` / `{% include %}` 引入。
4. **CSS / JS / 字体可自托管**：`assets/` 支持 `.css / .css.liquid / .js / .js.liquid`、png/jpg/jpeg/gif/svg/webp/ico，以及 **`.woff / .woff2 / .ttf / .eot`**；引用走 `shoplaza_asset_url` 过滤器 + `stylesheet_tag` / `script_tag`，平台经 CDN 分发；**无需外链 CDN 字体/脚本**。
5. **自定义页面**：后台 Online Store > Custom Page 提供富文本编辑器（标题 + 内容），官方文章**未确认存在原生 HTML 源码模式**；HTML 级静态页面需走主题 `page` 模板或自定义 section；dev API 有 custom-page 全套端点（list / create / retrieve / update / delete / count / search / batch）。
6. **平台托管、不可主题定制的边界**：模板类型清单共 18 类，含 index / product / collection / **cart** / blog / article / **page** / search / 404 / password / order / order-verify / customers/login / register / addresses / order / reset_password / reset_success；**清单中没有 checkout / payment / thank-you / order-confirmation 模板**。帮助中心口径：结账页仅可在主题编辑器内定制有限元素（结账 banner、订单摘要背景、支付信息背景）；更深的结账配置走 Checkout Premium 应用（应用商店标 Free，档位待核实）。
7. **套餐口径未写明代码锁定**：官方代码文档未把 Edit code 列成某付费档专属；帮助中心 Basic 背景截图下仍可见 Edit code 入口。但定价 FAQ 表述为"升级付费套餐后可完整定制"，**7 天试用内 Edit code 是否开放、免费预览店是否可进编辑器，均为 [待实机核实]**。

## 1. 逐项核对（对应调研五问）

### 1.1 在线代码编辑器与主题源码下载 / 上传

- 入口：Online Store > Themes → 主题 `...` → Edit code；多文件可同时打开，搜索框按文件名过滤；`cmd/ctrl+F` 搜索替换；未保存改动 Save 按钮高亮。
- 文件操作：相关目录下 Add a new file；选中文件可 copy / rename / delete。
- 版本回滚：保存后在文件内点 **Current**，下拉列出历次保存日期时间，选版本回退后 Save。
- 源码流转：Actions 菜单 Preview / Publish / Duplicate / Upgrade / Rename / **Download theme file** / Edit languages / **Edit code** / Delete；列表右上 **Upload theme**。
- 本地开发：官方建议大改用本地 IDE + Shoplazza CLI；本地编译链路文档未展开。

### 1.2 模板语言、section/snippet 注册机制、CSS/JS 追加位置、字体自托管

| 项 | 官方口径 |
| --- | --- |
| 语言 | Shoplazza Liquid：Liquid 标签 + HTML + CSS + JS + JSON；模板用 JSON 定义 section 布局 |
| 目录角色 | layout=每页 HTML 外壳（页头/页尾/全局脚本）；templates=18 类页面控制器；sections=可复用可编排模块；snippets=可复用 Liquid 片段；config=主题设置定义与取值；locales=前台与编辑器译文；assets=静态资源 |
| Section 注册 | `sections/*.liquid`，文件内 schema 定义 name / settings / blocks / presets；编辑器内可被添加到模板并排序；支持 app blocks |
| Section 专属资源 | Section assets：section 可绑定自己的 CSS/JS，不必全量塞全局文件 |
| Snippet 引入 | `{% render %}` 或 `{% include %}` |
| CSS/JS 追加 | 全局放 `assets/theme.css` / `assets/theme.js`，layout 内用 `stylesheet_tag` / `script_tag` 引用；局部样式进对应 section assets |
| 字体自托管 | `assets/` 接受 woff/woff2/ttf/eot；用 `shoplaza_asset_url` 引用；**Montserrat / Inter / Poppins 可自托管，不依赖外链字体 CDN** |
| 最佳实践 | 合并 CSS/JS 减少请求；无 Liquid 处理需求时用纯 `.css` / `.js`（免服务端渲染，更快）；图片优先 webp 并压缩 |

### 1.3 静态 HTML 页 / 自定义页面 HTML 模式

- 后台路径：Online Store > Custom Page > Add Page；填标题与富文本内容，Save；菜单 Online Store > Navigation 选 header/footer/policies，Add menu item 链接到该 Custom Page。
- 官方文章与截图只呈现富文本工具栏，**未披露源码（`<>`）编辑开关**；不要假设后台自定义页可贴整段 HTML。
- 要做代码级静态页（如评委模式导览页）：在代码编辑器内基于 `page` 模板/新建自定义 section 实现；或先验证富文本内粘贴 HTML 是否被保留（待实机）。

### 1.4 平台托管不可自定义边界（官方口径）

- **可主题定制**：首页、商品页、合集页、购物车 cart、博客/文章、静态页、搜索、404、密码页、客户登录/注册/地址/订单/找回密码等模板；结账页在主题编辑器内仅 banner、订单摘要背景、支付信息背景等有限元素。
- **无独立模板、平台托管**：checkout 结账流程页、payment 支付页、thank-you / order-confirmation 订单确认页。这些页面的字段顺序、支付方式展示、成功页结构不由主题模板控制；现场不得承诺对这些页面做代码级改造。
- 应用层补充：应用商店有 Checkout Premium（标注 Free，深度结账配置），其能力边界与计费待核实；捆绑、评价、会员等已知免费死路维持原调研结论不变。

### 1.5 草稿主题、发布机制与现场复现风险

- Preview：私有预览，不对外公开；可切换 PC/移动视图。
- 编辑器改动：Save draft 保存定制；**Publish** 后当前版本才上线；Duplicate 复制副本（"Copy of xx"）；Upgrade 取主题最新版且不覆盖当前版；Delete 删除后不可恢复。
- 代码保存：编辑器内 Save 即时写入主题文件；按文件版本回滚兜底。
- 现场 2 小时风险点：
  1. **入口开放度未知**：试用店内 Edit code 是否可见可写，开赛前先用 Preview 店/试用店实机确认；若锁定，本批代码增补全部降级为零代码路径（见 §3 方案 A）。
  2. **先备份再改**：动代码前 Duplicate 一份主题副本；关键文件 Save 前可 Download theme file 留档；出问题用副本或版本回滚恢复。
  3. **Liquid 语法错误**：单个 section/模板语法错误可导致对应页面白屏；改动保持小步、单文件保存、即时预览验证。
  4. **缓存与预览分离**：静态资源走平台 CDN；发布后若前台样式未刷新，需区分预览缓存与线上缓存；官方文档未给专门的编译/缓存刷新说明，列为待实机项。
  5. **自定义 section 暴露度**：新建 section 的 preset 是否被 Reformia 主题编辑器识别为可选模块，取决于主题 JSON 模板接入；若编辑器不显示，只能在模板代码内直接挂载。
  6. **字体/JS 加载**：自托管 woff2 与局部 JS 需在草稿预览里核对移动端加载与回退。

## 2. 套餐边界待核实项

- [ ] 7 天试用内 Edit code 入口是否开放、可保存可发布；
- [ ] 免注册预览店是否能进代码编辑器（预期不能，待确认）；

- [ ] 代码编辑器对新建 section/snippet 文件数量、文件大小有无限制；
- [ ] 发布后 CDN 缓存刷新入口与生效时长；

## 3. 方案 A / B / C 与时间 · 风险 · 评分收益估算

估算基线：现有 Runbook 设计配置 114 分钟、测试单 13 分钟、复查留证 25 分钟，合计 152 分钟，另留缓冲 10 分钟；现场窗口约 2 小时（120 分钟），增量改动必须留复查缓冲。评分收益参照《全球电商UI标杆调研.md》中 hover 反馈、卡片节奏、入场轻动效三类 P1/P2 可迁移项。

### 方案 A：零代码主题编辑器（默认基线，不动 Liquid）

- **做法**：只用 Reformia 既有区块、Theme settings、自定义页与富文本完成视觉台阶；不进 Edit code。
- **时间**：增量 15–25 分钟（区块顺序、配色、字体档位、按钮样式在编辑器内调整）。
- **风险**：低。不碰模板，无白屏/回滚需求；受区块能力上限约束。
- **评分收益**：仅覆盖区块可表达的对齐、留白、配色与既有 hover；自定义过渡时长、入场动效、自托管字体等表达不了。对应收益 P1 下半 / P2。
- **前提**：无；当前路径即可执行。

### 方案 B：轻代码增补（推荐，条件成立时）

- **做法**：Edit code 内只做三件事——`assets/` 内追加一个自定义 CSS 文件（过渡 150–300ms、hover 缩放 1.03、reduced-motion 降级）、一个轻量 IntersectionObserver JS（卡片入场淡入/上浮，禁外部 CDN）；必要时新增一个自定义 section 承载重复卡片节奏；字体按需自托管 woff2。**不改 cart/checkout/订单结构，不重构主题目录。**
- **时间**：30–45 分钟，含 Duplicate 备份、单文件保存、草稿预览 PC+移动核对、回滚演练。
- **风险**：中低。语法错误有文件版本回滚与主题副本兜底；主要不确定性是试用内编辑器开放度（先验入口）与 section preset 暴露度。
- **评分收益**：可落地标杆调研中 hover 反馈、卡片节奏、克制入场动效三类，对齐 Peak Design / Elgato 的交互颗粒度；对应 P1 可达成。收益依据：这些项在零代码区块内无对应开关，轻代码是免费约束下唯一补全路径。
- **前提**：实机确认 Edit code 在试用内可写；备份与回滚路径先走通；改动清单控制在上述范围。

### 方案 C：深度定制（现场窗口不推荐）

- **做法**：整站自定义主题重构、自建 section 体系、本地 CLI 开发后下载上传、自定义页 HTML 架构调整。
- **时间**：2–4 小时以上（含本地开发、上传、编译/缓存排障、移动端回归），超出 2 小时现场窗口。
- **风险**：高。Liquid 结构破坏导致白屏、CDN/预览缓存不一致、上传后主题版本错位；无完整回归时间。
- **评分收益**：边际有限——标杆调研中可迁移的视觉/交互项在方案 B 内已覆盖；深度定制主要换来结构性自由，对本次评审增量评分贡献小。
- **建议**：不作为现场选项；仅在赛后复盘阶段，在付费套餐与本地 CLI 环境内评估。

### 选择建议

现场先花 5 分钟实机确认 Edit code 入口：**可写**走方案 B，其余回归方案 A；**锁定**则全部方案 A，动效/字体类缺口在评审讲解中如实说明为主题区块限制，不虚构已实现。
