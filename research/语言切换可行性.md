# Shoplazza 多语言 / 翻译能力可行性结论 · ShotStart

> 用途：为 ShotStart 独立站（Shoplazza + 免费主题 Reformia）是否、以及以什么方式支持多语言（中英切换）给出可落地判定。
> 调研时间：2026-11-20；调研范围：官方帮助中心、开发者文档、应用商店、定价页公开信息。
> 约束：本结论不修改任何店铺后台配置；未获确认前，不在店内安装插件、不改动语言/市场设置。页面文案以 `shotstart-copy\pages\` 现状为准，本轮不改 pages。

## 0. 结论先行

**判定：分层可行，多语言不能作为现场 P0 依赖。**

1. **主题固定文本**（按钮、表单标签、通用提示、导航等主题自带文案）：走原生后台，**不需要付费应用**——Settings > Languages 添加语言；Online Store > Themes > 目标主题 `...` > Edit languages，可手工翻译，也支持 Auto translate 与 Untranslated 筛选；开发侧对应 `locales/` 下的翻译键值文件。
2. **自定义内容**（商品标题/描述、菜单、自定义页面、营销活动文案等）：原生后台不提供逐条翻译，需安装应用商店的 **Multi-Language Translator**（开发者 Shoplazza，应用商店标注 **Free**；双语并排可视化编辑、机器翻译首发后手工精修、按模块与地区管理、支持导出/导入翻译表格）。
3. **前台语言切换器**：**不是**主题页头原生挂件。需启用 **Geolocation**（标注 Free）后，页面才出现语言/地区选择器；另有 **Language Switch**（标注 Free）做零代码翻译与切换。
4. **市场绑定**：语言必须在 Settings > Markets > Domain and languages 配置到对应市场后才对消费者可见；未完成翻译的内容回退主市场默认语言。

**关键风险**：Shoplazza 没有公开的"永久免费套餐"，只有 **7 天免费试用**与免注册预览店；付费起步 Basic $39/月（年付 $29.25/月，2% 交易费）。上述两个翻译/地区插件在**试用店内是否完整可用、是否存在内购升级档位、与 Reformia 主题是否兼容**，官方文档与应用列表页未逐条写明，状态为 **[待实机核实]**。评审面向英语评委，建议多语言只作备选，不阻塞主店搭建。

- 来源：https://www.shoplazza.com/pricing

## 2. 原生能力路径（无需插件的部分）

| 能力 | 后台路径 | 说明 |
| --- | --- | --- |
| 添加支持语言 | Settings > Languages > Add language | 语言列表管理；开发侧对应 `locales/`（如 en-US.json / fr.json） |
| 翻译主题文本 | Online Store > Themes > 目标主题 `...` > Edit languages | 原文左 / 译文右手工编辑；支持 Auto translate、Untranslated 筛选；保存后更新默认内容 |
| 语言挂到市场 | Settings > Markets > Domain and languages | 未绑定到市场的语言不对外可见；缺译内容回退主市场默认语言 |

开发侧最佳实践：模板文案用翻译键 + `t` 过滤器，键前缀 `i18n.`；插值用命名参数；官方文档注明**不支持按数量的复数形式**（pluralization）。

## 3. 依赖插件的部分（状态：Free 标签，档位待核实）

| 插件 | 应用商店标注 | 职责 | 待核实项 |
| --- | --- | --- | --- |
| Multi-Language Translator | Free | 商品/导航/页脚等自定义内容并排双语编辑、机器翻译首发、手工精修、按地区存译文、表格导出导入 | 是否有付费档位、试用内功能上限、Reformia 兼容性 |
| Geolocation | Free | 按访客地区展示个性化内容；启用后前台出现语言/地区选择入口 | 切换器在 Reformia 页头的落点与样式可定制度 |
| Language Switch | Free | 零代码多语言翻译与可定制语言切换器 | 与上两者功能重叠，安装前只取其一 |

> 注：应用列表页的 "Free" 是安装标签，不等同全部功能永久免费；个别同类翻译插件标 7-day free trial。现场若要使用，先在试用店内打开插件详情页确认计费与额度，再决定是否启用。

## 4. 替代方案（插件不可用 / 需付费时，不依赖店内切换）

按优先级：

1. **首屏"中文导览 / 评委模式"自定义页**：Online Store > Custom Page > Add Page 建一页中英对照导览（品牌、三件/八件商品、挑战闭环、演示路线），挂页头菜单或首屏按钮；评委可从该页进入讲解。页面本身在英文店内以富文本维护，不触发翻译插件与市场配置。
2. **中英对照物料随演示提供**：现有 `shotstart-demo\AI应用与创新举证材料.docx` 已是中英双栏对照（项目概述、商品、举证用途等），评审时可直接打开对照；无需在店内做语言切换。
3. **兜底**：主店保持英语单语，页尾/联系方式处保留一句中文导览说明链接到对照文档；不强行做多市场结构。
