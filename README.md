> 「别人用 AI 建站，我把 AI 做成了店里的一件商品。」
>
> 本仓库是 2026 AI 独立站挑战赛（高校专场）参赛作品 **ShotStart** 的完整项目归档，在店铺平台试用期到期前整理留存。

## 项目概况

- **名称**：ShotStart —— 面向美国新手短视频创作者的拍摄装备英文独立站
- **时间线**：2026-11-19/20 学习 Shoplazza + Athena 建站 → 2026-11-21 河南工业大学现场比赛（一天建站 + 路演答辩）→ 2026-11-22 归档
- **赛事**：2026 AI 独立站挑战赛 · 郑州高校专场，由店匠 Shoplazza 与 Athena、易赛诺、易跨境电商学苑联合主办，河南工业大学承办；郑州 11 所高校百余名学生同场，个人形式参赛
- **评分维度**：站点完整度 60 分 / AI 创新应用 25 分 / 选品与商业链路 10 分 / 现场效率与展示 5 分

## 作品内容

- **店铺**：12 件单品 + 2 个捆绑套装，九个页面齐全；满 $35 免邮、新客码 NEWCREATOR10、套装码 STARTERKIT 均前台实测
- **选品逻辑**：三件套捆绑客单价 $38.22 恰好跨过 $35 免邮门槛（单买 $44.97），清洁布与补充装为天然复购耗材——用定价结构引导首单转化
- **AI 助手 ShotStarter**：选平台（TikTok / Instagram Reels / YouTube Shorts）+ 商品 + 卖点，一键生成 15 秒带货脚本、四镜分镜表、发布文案与话题标签；比赛现场使用离线原型演示，上线版本接生成式模型
- **增长闭环**：装备销售 → 内容生产 → 社媒传播 → 7 天挑战留资 → 耗材复购
- **品牌视觉**：全站 24 张场景图由 AI（Seedream 5.5）统一生成，暖白 / 深海军蓝 / 珊瑚橙三色体系，每页专属背景；素材 URL 见 `contest/视觉素材清单_全站24张场景图.md`

## 诚实边界（比赛日口径）

- 价格、折扣与有效期均为**演示配置**，页面明确标注 Demo
- 商品尺寸、重量、兼容性等参数**保留占位**，未经供应商核验不编造
- 未虚构任何销量、评分、评价数、认证、奖项、库存数或保修年限
- 现场演示助手为离线模板原型，不把模拟生成说成上线版本
